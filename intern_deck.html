Slide 2: Problem Statement Identified by Team
02 / 12
1. Packaging Waste in Online Meat Delivery
  • Current D2C brands use disposable corrugated boxes, non-recyclable bubble wrap, and thermocol inner linings on every order.
  • Consumers in urban apartments dislike the accumulation of single-use insulation packaging after every weekend meal.
  • Packaging waste represents an unnecessary cost for both the consumer and the environment.
2. The Cold-Chain "Black Box"
  • Consumers are told their meat is "chilled at 0°C to 4°C", but they have no way to verify if the delivery thawed during long traffic transit.
  • When ambient temperature exceeds 30°C in Indian summers, ice packs melt, resulting in soggy cuts or compromised freshness.
  • Lack of real-time temperature visibility creates hesitation among first-time buyers.
3. Fragmented Return Logistics
  • Existing companies have not attempted reusable containers because return logistics are perceived as complex.
  • Without an immediate financial incentive (like an automated UPI refund), customers have no motivation to hand back containers.
  • Our project aims to prove that a circular deposit loop is technologically and operationally viable.
Our Project Goal for this Internship Sprint

Demonstrate that an Indian meat D2C platform can deliver fresh blast-chilled cuts in 100% reusable cold-boxes with live IoT temperature telemetry and an instant ₹250 UPI deposit refund system.

Slide 3: Proposed Solution — The Sagar Fresh Model
03 / 12
1. Reusable Cold-Gel Vault Container

Instead of cardboard and throwaway thermocol, deliveries are fulfilled in reusable, food-grade thermal vaults with frozen phase-change cold gel blocks capable of maintaining sub-4°C chill for hours.

2. Real-Time IoT Temperature Telemetry

Every active delivery stream simulated temperature sensor readings directly to the customer's order tracking page, allowing users to verify that their meat remained at 0°C to 4°C during dispatch.

3. Automated ₹250 Refundable Box Deposit

A ₹250 container deposit is added to checkout. Customers can either return the empty box immediately to the delivery driver or schedule an automated return pickup via the web app.

4. Instant Doorstep UPI Refund Reversal

Once the return partner collects the container, the ₹250 deposit is credited back to the customer's UPI ID (Google Pay, PhonePe, or Paytm) or converted into wallet credit.

Circular Experience Flow Built in Demo Prototype

[Customer Orders Cut + ₹250 Deposit] ➔ [Chilled Dispatch in Reusable Box] ➔ [Live Temp Tracking 0°C-4°C] ➔ [Delivery] ➔ [1-Click Return Request] ➔ [₹250 UPI Refund]

Full-Stack Implementation & Architecture
Slide 7: Technology Stack & Database Architecture
07 / 12
Frontend Architecture
  • Framework: React 19 Single Page Application built with Vite 8.
  • Styling: Tailwind CSS v4 with custom responsive utilities.
  • State & Routing: Client-side dynamic state for cart, authentication, and live IoT polling.
  • Asset Delivery: Production-built bundle (`client/dist`) ready for edge CDN caching.
Backend API & Database Architecture
  • Server: Node.js with Express 4 RESTful API routes.
  • Authentication: JSON Web Tokens (JWT) with bcrypt credential encryption.
  • Cloud Database: Live MongoDB Atlas Cluster (`cluster0.6rm7klj.mongodb.net`) managed via Mongoose ODM schemas.
  • Collections: `users`, `products`, `orders`, `coolers`, and `coolerreturns`.
Zero-Crash Dual-Persistence Resilience

Engineered an intelligent failover layer: when MongoDB Atlas is connected, queries read and write live from the cloud database; if internet access drops during an offline demo, the server automatically falls back to an atomic local JSON snapshot without crashing.

Cold-Chain Innovation & IoT Monitoring
Slide 8: Live IoT Cold-Chain Temperature Telemetry
08 / 12
How the Live IoT Simulation Works
  • Every order placed on Sagar Fresh is assigned a specific reusable cooler unit from the fleet (e.g. `BOX-BLR-102`).
  • The container is equipped with a digital temperature probe logging core readings in real time.
  • The customer's Order Tracking Page renders an interactive temperature graph showing values strictly between 0°C and 4°C.
  • Includes a simulated "Simulate IoT Probe" test trigger to demonstrate live sensor telemetry updates to the manager.
Consumer Confidence & Safety Verification
  • Visual Temperature Gauge: Displays green indicator when inside the safe 0°C–4°C FSSAI range.
  • Transit Duration Timer: Shows estimated arrival within 90 minutes.
  • Delivery Partner Pod Details: Assigns delivery rider contact and vehicle details (EV Insulated Pod).
  • Completely removes consumer doubts regarding meat freshness during transit.
